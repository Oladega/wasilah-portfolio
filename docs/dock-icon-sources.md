# Dock icon sources

Dock order is LinkedIn, Email, LinkedIn profile, Phone, matching the requested duplicate LinkedIn positions. Both LinkedIn items open the supplied profile.

- LinkedIn: actual iOS app artwork returned by Apple's public lookup API for app ID 288429040, downloaded 18 October 2026: https://itunes.apple.com/lookup?id=288429040. Local file: `public/images/dock/linkedin.jpg`.
- Mail: PNG converted from the installed Apple Mail app icon at `/System/Applications/Mail.app/Contents/Resources/ApplicationIcon.icns` using macOS `sips`. Local file: `public/images/dock/mail.png`.
- Phone: PNG converted from the installed Apple Phone app icon at `/System/Applications/Phone.app/Contents/Resources/AppIcon.icns` using macOS `sips`. Local file: `public/images/dock/phone.png`.

These are app icon assets, not generic glyphs. They identify their respective contact destinations. Logos remain the property of their respective owners.
